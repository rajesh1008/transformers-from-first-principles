  - the pool first gave only 3,074 windows, too few for 400 steps of one pass, so the budget became 384 steps (one pass exactly);
  - the first held-out slice of Sylvie and Bruno Concluded was publisher's advertisements and transcriber's notes; it is now cut at "THE END.";
  - the first contamination check compared the held-out set against whole books and reported 2,003 of 2,003 13-grams shared; the check
    must compare against the decoded training pool, which is what data_facts.py does;
  - stream.py's first resume test keyed windows by position, not by their bytes, and counted batches beyond one pass; both fixed;
  - a repeat of cur_easy with seed 7 under load ended 0.0001 away from the first run (5.2852 / 5.0904 against 5.2851 / 5.0903): one-thread
    CPU runs are close to, but not exactly, bit-for-bit repeatable here;
  - mix50 with seed 1865 looked best on Looking-Glass (5.0027); seed 7 gave 5.3883, so the chapter reports the spread, not a winner.
