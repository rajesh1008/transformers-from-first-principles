Chapter 16 scripts, run from 04-code/ch16 (NumPy only; matplotlib for figures). Order used for the book:
fetch.py  count.py  tied_check.py  memory.py  cost.py  running_sentence.py  lab16.py  solutions.py
Helpers: _common.py (sets one CPU thread before NumPy loads, names the three public models, loads their
configuration files and weights-file headers from configs/) and reader.py (the configuration reader: spec()
turns a GPT-2, Llama-style or Qwen3 config.json into one dict of settings; tiny_spec() does the same for
Tiny's constructor arguments; count() counts learned numbers part by part; kv_numbers_per_token()).
Network: fetch.py and tied_check.py read from huggingface.co (config.json, and the first bytes of each
model.safetensors by range request; no weights are downloaded). Fetched 10 November 2026; the results are
kept in configs/, so the other scripts run offline.
    python3 fetch.py > outputs/fetch.txt
    python3 count.py > outputs/count.txt           (also writes outputs/count.json)
    python3 tied_check.py > outputs/tied_check.txt (three rows of Qwen3-0.6B's two stored tables, 6 KB each)
    python3 memory.py > outputs/memory.txt         (also writes outputs/memory.json)
    python3 cost.py > outputs/cost.txt             (one thread, fastest of five; about 10 seconds)
    python3 running_sentence.py > outputs/running_sentence.txt
    python3 lab16.py > outputs/lab16.txt
    python3 solutions.py > outputs/solutions.txt   (about 15 seconds)
