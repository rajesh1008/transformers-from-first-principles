Things that went wrong or changed on the way, and are told in the chapter:
  - Chapter 24's train_tiny.py would have overwritten its checkpoints; this copy adds _wd and _o to the run tag.
  - The all-token ECE first printed as 0.0000; the format was changed to show 1.56e-05.
  - The constructed distractors include a fragment ("ecture") cut from a hyphenated word; kept and named in the text.
  - judge.py: the API refused a temperature setting for this model ("temperature is deprecated"), so default sampling is used and a rerun
    will not repeat every answer.  With a 5-token limit and default settings the replies were empty (the model spent the tokens on
    internal reasoning); the first run scored 0.01.  The run used in the chapter turns extended thinking off, adds a one-line system
    instruction asking for a single character, allows 40 tokens and keeps every raw reply.  16 of 200 cloze replies named the source
    book instead of a letter and are scored wrong.
  - The API key is read into judge.py's process only; lab25.py checks that the key string appears in no file under 04-code/ch25.
